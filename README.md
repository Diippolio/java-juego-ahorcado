# Juego de Ahorcado en JAVA

![Logo de JAVA](https://www.muylinux.com/wp-content/uploads/2020/03/java.png)

Hicimos un juego de ahorcado en JAVA donde uno debe ir colocando letra a letra en la consola y tiene cierta cantidad de intentos. Si logra completar toda la palabra uno gana, caso contrario, de que se acaben intentos, uno pierde.

## ¿Qué herramientas utilizamos?

1. Clase Scanner
2. Declaraciones y asignaciones
3. Arreglos
4. Estructuras de control: Iterativa (Bucle)
5. Clase String y sus métodos valueOf, length() y charAt
6. Clase Character y su método toLowerCase
7. Estructura de control: condicional  if
